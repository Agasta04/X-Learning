A. Pengolahan Data

"Data mentah belum memiliki makna. Melalui proses pengolahan, data berubah menjadi informasi yang berkualitas — akurat, relevan, dan dapat digunakan untuk mengambil keputusan."

Data Mentah → Informasi Berkualitas:

Data Mentah
Tidak terstruktur, tanpa makna
Proses Komputasi
Sorting, filtering, agregasi
Informasi Berkualitas
Siap untuk pengambilan keputusan

Ciri-ciri Data yang Berkualitas:

Akurat

Data sesuai dengan kenyataan, tidak ada kesalahan penulisan atau pengukuran.

Aktual

Data masih relevan dan terbaru, belum usang atau kedaluwarsa.

Lengkap

Tidak ada bagian penting yang hilang atau kosong.

Konsisten

Format dan satuan data seragam di seluruh kumpulan data.

Contoh Nyata: Data mentah nilai ujian siswa (78, 85, 90, 65, 72) belum bermakna. Setelah diolah (diurutkan, dihitung rata-rata, dikelompokkan), kita mendapatkan informasi: "Rata-rata kelas = 78, nilai tertinggi 90, nilai terendah 65" — inilah informasi berkualitas.

B. Konsep Struktur Data & List

Struktur Data adalah cara mengorganisir dan menyimpan data di dalam komputer sehingga dapat diakses dan dimanipulasi secara efisien. Memilih struktur data yang tepat sangat menentukan kecepatan dan efisiensi program.

List (Array / Daftar):

List adalah struktur data paling dasar: kumpulan elemen yang disusun berurutan (indeks 0, 1, 2, ...). Setiap elemen dapat diakses langsung melalui indeksnya.

Contoh List Nilai Ujian: [78, 85, 90, 65, 72]

[0]78
[1]85
[2]90
[3]65
[4]72
Arahkan kursor ke salah satu sel untuk melihat detail indeks.

Karakteristik List:

  • Elemen tersusun berurutan dengan indeks mulai dari 0.
  • Akses elemen berdasarkan indeks sangat cepat (O(1)).
  • Penambahan/penghapusan di tengah list relatif lambat karena harus menggeser elemen lain.
  • Cocok untuk data yang jarang berubah dan sering diakses berdasarkan indeks.

Analogi: List seperti rak buku bernomor — kamu bisa langsung mengambil buku di rak nomor 3 tanpa harus memeriksa rak sebelumnya.

C. Stack (Tumpukan) — LIFO

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out): elemen yang terakhir dimasukkan adalah elemen yang pertama kali dikeluarkan.

Analogi: Tumpukan piring di rak. Piring yang diletakkan paling akhir (paling atas) adalah yang paling mudah diambil. Untuk mengambil piring paling bawah, kita harus mengeluarkan semua piring di atasnya terlebih dahulu.

Operasi Utama Stack:

Push

Menambahkan elemen baru ke atas tumpukan.

Pop

Mengambil dan menghapus elemen paling atas.

Peek

Melihat elemen teratas tanpa menghapusnya.

Contoh Penerapan:

  • Tombol Undo di aplikasi — aksi terakhir dibatalkan lebih dulu.
  • Navigasi browser — tombol "Back" mengembalikan ke halaman sebelumnya.
  • Tumpukan piring di restoran.
  • Pemanggilan fungsi dalam pemrograman (call stack).

D. Queue (Antrean) — FIFO

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out): elemen yang pertama kali dimasukkan adalah elemen yang pertama kali dikeluarkan.

Analogi: Antrean di kasir. Orang yang datang pertama akan dilayani pertama. Orang yang baru datang harus mengantre di belakang.

Operasi Utama Queue:

Enqueue

Menambahkan elemen baru ke belakang antrean.

Dequeue

Mengambil dan menghapus elemen paling depan.

Front

Melihat elemen terdepan tanpa menghapusnya.

Contoh Penerapan:

  • Antrean printer — dokumen dicetak sesuai urutan pengiriman.
  • Antrean pesan WhatsApp/email — pesan ditampilkan urut waktu kirim.
  • Antrean pembelian tiket di bioskop.
  • Antrean proses CPU pada Sistem Operasi.

Perbandingan Singkat Stack vs Queue:

Aspek Stack (LIFO) Queue (FIFO)
Prinsip Last In, First Out First In, First Out
Operasi Utama Push & Pop Enqueue & Dequeue
Ujung Aktif Satu ujung (atas) Dua ujung (depan & belakang)
Analogi Tumpukan piring Antrean di kasir

E. Sekilas Struktur Data Lain

Selain List, Stack, dan Queue, masih banyak struktur data lain yang akan kamu pelajari di jenjang berikutnya. Berikut beberapa di antaranya sebagai wawasan tambahan.

Linked List

Elemen saling terhubung melalui pointer, bukan berurutan di memori. Lebih fleksibel untuk penambahan/penghapusan elemen dibanding Array, tetapi akses membutuhkan penelusuran.

Tree & Binary Search Tree

Struktur hierarkis untuk pencarian cepat, seperti daftar kontak atau direktori file di komputer. Tree yang terurut memungkinkan pencarian dalam O(log n).

Graph

Kumpulan simpul (node) yang terhubung oleh sisi (edge). Digunakan untuk memodelkan peta, jaringan sosial, rute navigasi, dan Internet.

Dictionary / Hash Map

Struktur pasangan key–value untuk pencarian super cepat. Contoh: kamus bahasa, data pengguna (NIS → profil siswa).

Tips: Untuk saat ini, fokuskan dulu pada List, Stack, dan Queue. Struktur data lain akan sangat mudah dipahami setelah kamu menguasai tiga ini.
