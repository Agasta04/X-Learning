A. Alur dari Masalah ke Program

Sebuah program komputer tidak muncul begitu saja. Ia melewati 4 tahap translasi dari ide di kepala sampai menjadi kode yang bisa dijalankan mesin.

1. Masalah

Rumusan persoalan yang ingin diselesaikan

2. Algoritma

Langkah-langkah logis penyelesaian

2b. Flowchart

Visualisasi alur logika dengan simbol

3. Pseudocode

Notasi antara bahasa manusia dan komputer

4. Program

Kode yang bisa dijalankan komputer

Model I-P-O

Input → Proses → Output

Analogi: Seperti membangun rumah — algoritma adalah gambar denah, flowchart adalah blue-print visual, pseudocode adalah instruksi kerja untuk tukang, dan program adalah rumah yang berdiri.

B. Konsep Dasar Algoritma

Algoritma adalah urutan langkah-langkah logis dan terstruktur untuk menyelesaikan suatu masalah. Komputer tidak dapat berpikir sendiri — ia hanya menjalankan perintah.

Analogi: Algoritma seperti resep membuat mie instan.

Lima Ciri Algoritma yang Baik (Donald E. Knuth)

Ciri Penjelasan Contoh
Input Ada bahan atau data yang diproses. Nilai ujian, nama, angka.
Output Ada hasil akhir yang dihasilkan. Tulisan "LULUS", total belanja.
Finiteness Program tahu kapan harus berhenti. Selesai setelah mencetak hasil.
Definiteness Instruksi jelas, tidak ambigu. "Tambah 5", bukan "tambah sedikit".
Effectiveness Langkahnya masuk akal dan efisien. Tidak melakukan hal yang sia-sia.

Tiga Jenis Alur Algoritma

Jenis Alur Pengertian Contoh
Sequence Langkah dikerjakan berurutan. Input → hitung → tampilkan.
Branching Pemilihan berdasarkan kondisi. Jika nilai ≥ 75, cetak LULUS.
Looping Langkah diulang selama kondisi terpenuhi. Angka 1 sampai 10.

C. Diagram Alir (Flowchart)

Jika algoritma adalah teksnya, maka flowchart adalah gambar visualnya. Flowchart memakai bentuk-bentuk geometris untuk menggambarkan alur program.

Simbol-Simbol Wajib Flowchart (Standar ANSI/ISO)

Simbol Nama Deskripsi
Garis Alir (Flowline) Arah yang menunjukkan aliran program dari awal hingga akhir.
Terminator Titik awal (START) atau titik akhir (END) suatu program.
Proses Kegiatan komputasi: operasi aritmatika, pemrosesan data, assignment, dsb.
Keputusan (Decision) Titik percabangan di mana salah satu cabang dipilih berdasarkan suatu kondisi (Ya/Tidak).
Masukan / Keluaran (Input/Output) Melambangkan saat program menerima data (input) atau menampilkan hasil (output).
Subprogram Melambangkan suatu kegiatan atau proses lain yang telah didefinisikan sebelumnya (dipanggil).
Penghubung dalam Halaman Menghubungkan satu titik pada diagram alir ke titik lain pada halaman yang sama.
Penghubung antar Halaman Menghubungkan titik pada diagram alir ke halaman berbeda (untuk diagram kompleks).

Aturan Emas Membuat Flowchart

  1. Mulai dengan simbol Start dan akhiri dengan End.
  2. Gunakan simbol yang sesuai dengan fungsinya.
  3. Arah alur umumnya dari atas ke bawah.
  4. Setiap keputusan memiliki minimal dua jalur: Ya dan Tidak.
  5. Tuliskan instruksi secara singkat dan jelas.

Contoh 1: Cek Kelulusan Ujian

Aturan: Jika nilai ≥ 75, cetak "LULUS". Jika di bawah 75, cetak "TIDAK LULUS".

Contoh 2: Membuat Mie Instan

Contoh 3: Apakah Hari Ini Hujan?

Contoh 4: Menelusuri Flowchart (Tracing)

Perhatikan flowchart berikut:

Jika angka = 5, berapa outputnya?

  • Input angka = 5
  • hasil ← 5 × 2 = 10
  • print hasil → 10
  • Output = 10

D. Pseudocode (Kode Semu)

Pseudo berarti tiruan, code berarti kode. Pseudocode adalah bahasa jembatan antara bahasa manusia dan komputer.

Aturan Penulisan:

  • Gunakan kata kunci: INPUT, OUTPUT, IF, ELSE, WHILE, FOR.
  • Fokus pada logika, bukan tanda baca.
  • Gunakan indentasi.
  • Satu baris untuk satu pernyataan.

Contoh 1: Menghitung Luas Persegi

Pseudocode 
Algoritma Menghitung Luas Persegi
Input: Nilai Panjang Sisi Persegi
Output: Luas Persegi tercetak

input sisi
luas ← sisi * sisi
print luas

Jika sisi = 5, outputnya 25.

Contoh 2: Membagi Bilangan

Pseudocode dengan Kondisi 
Algoritma Membagi Bilangan
Input: Pembilang dan Penyebut
Output: Hasil Pembagian tercetak

input pembilang, penyebut
if penyebut = 0
    print "Penyebut tidak boleh nol"
else
    hasil ← pembilang / penyebut
    print hasil

Jika penyebut = 0, outputnya "Penyebut tidak boleh nol".

Contoh 3: Menghitung Mundur dari N

Pseudocode Perulangan 
Algoritma Menghitung Mundur dari N hingga 1
Input: Nilai N
Output: Angka hitung mundur dari N sampai 1

input N
while N > 0
    print N
    N ← N - 1

Jika N = 5, outputnya 5 4 3 2 1.

Flowchart
Diagram visual alur program memakai simbol geometris.
Pseudocode
Kode semu mirip bahasa pemrograman.
Variabel
Wadah penyimpan nilai.
Input
Data yang dimasukkan ke dalam program.
Output
Hasil yang ditampilkan program.
Sequence
Alur program berurutan dari atas ke bawah.
Branching
Percabangan berdasarkan kondisi.
Looping
Perulangan langkah selama kondisi terpenuhi.
Tracing
Menelusuri alur program langkah demi langkah.
Terminator
Simbol flowchart untuk awal/akhir program.
Decision
Simbol flowchart untuk keputusan kondisi.
