A. Konsep Algoritma

"Algoritma adalah langkah-langkah logis dan sistematis yang digunakan untuk menyelesaikan suatu persoalan."

Ciri-ciri Algoritma yang Baik:

  • Memiliki awal dan akhir (terbatas / finite).
  • Setiap langkah didefinisikan dengan jelas, tidak ambigu.
  • Memiliki masukan (input) dan keluaran (output).
  • Langkah-langkahnya efektif dan dapat dijalankan.

Contoh dalam Kehidupan Sehari-hari:

Mencari Buku

Mencari buku di rak perpustakaan berdasarkan urutan abjad pengarang atau judul.

Resep Masakan

Langkah-langkah terurut memasak mie instan dari merebus air hingga siap dihidangkan.

B. Searching (Pencarian)

Searching adalah proses mencari data tertentu (target) dari sekumpulan data. Hasilnya: data ditemukan atau tidak ditemukan.

1. Linear Search

Memeriksa setiap elemen data satu per satu secara berurutan dari awal hingga akhir atau sampai data ditemukan.

Kelebihan

Mudah dipahami. Bisa dipakai pada data yang belum terurut (acak).

Keterbatasan

Lambat jika datanya banyak karena harus mengecek satu per satu.

2. Binary Search

Mencari dengan cara membagi dua area pencarian. Mengecek nilai tengah, jika target lebih kecil, cari di belahan kiri. Jika lebih besar, cari di belahan kanan. Ulangi sampai ditemukan atau area habis.

Syarat Wajib: Data harus sudah dalam keadaan terurut (dari kecil ke besar atau sebaliknya).
Kelebihan

Jauh lebih cepat pada data besar (O(log n)).

Keterbatasan

Hanya untuk data yang sudah terurut.

C. Sorting (Pengurutan)

Sorting adalah proses mengatur ulang sekumpulan data agar tersusun berdasarkan aturan tertentu (misal: dari kecil ke besar atau ascending).

1. Bubble Sort

Membandingkan elemen yang berdekatan dan menukarnya jika posisinya salah. Proses diulang berkali-kali sampai tidak ada lagi yang perlu ditukar.

Dinamakan "Bubble" (gelembung) karena nilai terbesar akan perlahan "naik" ke posisi paling akhir.

2. Insertion Sort

Membagi data menjadi dua bagian: "sudah terurut" (kiri) dan "belum terurut" (kanan). Algoritma mengambil satu elemen dari bagian belum terurut, lalu menyisipkannya (insert) ke posisi yang tepat di bagian yang sudah terurut. Mirip cara kita mengurutkan kartu di tangan.

3. Selection Sort

Memindai (scan) seluruh elemen yang belum terurut untuk mencari nilai paling kecil, lalu langsung menukarnya ke posisi paling depan dari area yang belum terurut tersebut.

D. Studi Kasus & Perbandingan Algoritma

Setiap algoritma punya kelebihan dan kekurangan. Memilih algoritma yang tepat akan membuat program lebih cepat dan efisien.

Tabel Perbandingan:

Algoritma Data Syarat Kecepatan (Rata-rata) Cocok Untuk
Linear Search Bebas (acak/urut) O(n) — lambat Data kecil, seadanya
Binary Search Harus terurut O(log n) — cepat Data besar, pencarian sering
Bubble Sort Bebas O(n²) — lambat Belajar konsep, data kecil
Insertion Sort Bebas O(n²), cepat jika hampir terurut Data kecil–menengah
Selection Sort Bebas O(n²) — selalu sama Data kecil, swap minimal

Studi Kasus Nyata:

Daftar Kontak HP

Kontak HP sudah tersusun berdasarkan abjad. Untuk mencari nomor seseorang, sistem bisa memakai Binary Search agar instan meskipun kontaknya ribuan.

Papan Skor Game

Skor pemain yang terus masuk harus diurutkan real-time. Sistem biasanya pakai Insertion Sort karena data hampir selalu terurut.

Mesin Pencari

Google menggunakan varian pencarian berbasis Binary Search + struktur data Tree untuk menemukan kata di miliaran halaman dalam milidetik.

Absensi Kelas

Guru mengecek nama satu per satu dari daftar hadir. Itu contoh Linear Search yang paling sederhana.

Intinya: Tidak ada algoritma "terbaik" untuk semua kasus. Pilih algoritma yang sesuai dengan ukuran data, apakah data terurut, dan seberapa sering operasi dilakukan.

E. Pseudocode

Pseudocode adalah cara menulis algoritma menggunakan bahasa yang mirip kode program tetapi tetap mudah dibaca manusia. Pseudocode tidak terikat bahasa pemrograman tertentu.

Linear Search 

FUNCTION LinearSearch(data, target):
    FOR i FROM 0 TO length(data) - 1:
        IF data[i] == target THEN
            RETURN i          // ditemukan di indeks i
        END IF
    END FOR
    RETURN -1                 // tidak ditemukan
END FUNCTION

Binary Search 

FUNCTION BinarySearch(data, target):
    left  = 0
    right = length(data) - 1
    WHILE left <= right:
        mid = (left + right) / 2
        IF data[mid] == target THEN
            RETURN mid
        ELSE IF data[mid] < target THEN
            left = mid + 1
        ELSE
            right = mid - 1
        END IF
    END WHILE
    RETURN -1
END FUNCTION

Bubble Sort 

PROCEDURE BubbleSort(data):
    n = length(data)
    FOR i FROM 0 TO n - 2:
        FOR j FROM 0 TO n - i - 2:
            IF data[j] > data[j + 1] THEN
                TUKAR data[j] dengan data[j + 1]
            END IF
        END FOR
    END FOR
END PROCEDURE

Insertion Sort 

PROCEDURE InsertionSort(data):
    FOR i FROM 1 TO length(data) - 1:
        key = data[i]
        j   = i - 1
        WHILE j >= 0 AND data[j] > key:
            data[j + 1] = data[j]
            j = j - 1
        END WHILE
        data[j + 1] = key
    END FOR
END PROCEDURE

Selection Sort 

PROCEDURE SelectionSort(data):
    n = length(data)
    FOR i FROM 0 TO n - 2:
        minIdx = i
        FOR j FROM i + 1 TO n - 1:
            IF data[j] < data[minIdx] THEN
                minIdx = j
            END IF
        END FOR
        IF minIdx != i THEN
            TUKAR data[i] dengan data[minIdx]
        END IF
    END FOR
END PROCEDURE

F. Kamus / Istilah Penting

Algoritma
Langkah-langkah logis dan sistematis untuk menyelesaikan masalah.
Target / Key
Nilai spesifik yang sedang dicari dalam proses Searching.
Perbandingan (Compare)
Proses melihat dua nilai untuk menentukan sama, lebih besar, atau lebih kecil.
Pertukaran (Swap)
Proses menukar posisi dua elemen data dalam daftar.
Data Terurut (Sorted)
Data yang sudah tersusun rapi, misal dari terkecil ke terbesar (Ascending).
Pseudocode
Cara menulis algoritma dengan bahasa mirip kode program, tapi mudah dibaca manusia.
Kompleksitas Waktu (Time Complexity)
Ukuran seberapa cepat algoritma berjalan seiring bertambahnya jumlah data (misal O(n), O(log n), O(n²)).
Best / Worst Case
Kondisi terbaik (kebetulan langsung ketemu) dan terburuk (harus periksa semua) dari sebuah algoritma.
Stable Sort
Sorting yang tidak mengubah urutan elemen-elemen yang nilainya sama.
In-Place
Algoritma yang mengurutkan tanpa butuh memori tambahan signifikan.
